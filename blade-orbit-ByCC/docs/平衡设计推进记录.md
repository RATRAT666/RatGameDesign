## 2026-11-06 · 环刀、远程与精英遭遇

讨论基线为游戏 v0.4.4。

### 已定方向

- **环刀满配应能轻松清小怪。** 只叠环刀、没有补远程手段，应在面对部分精英和多数 Boss 时明显吃力。补远程是构筑决策，清潮够用后继续叠剑有机会成本。
- **中期可以加入精英遭遇。** 让少量高威胁目标提供不同于清潮的战斗场合。精英存活期间暂停常规刷怪，是优先考虑的做法。

### 当前判断

- 「再添一剑」同时增加输出、击退和挡弹覆盖。每把剑独立结算命中冷却，挡弹没有次数限制。叠加转速、剑体积和外环后，敌人与弹头都难以接近。试玩已观察到环刀过于安全。
- 锁链优先抓近处未占用的目标，连接期间只有首次命中伤害。小怪多时容易先抓杂兵，单独打 Boss 时也无法用多条链集中输出。锁链更适合给近战创造输出机会，天雷则提供远程伤害。
- 先试一次精英遭遇，观察纯环刀是否真的要冒险追击，以及锁链能否明显减少追击成本。候选是会后撤和发弹、可被拉动的远程精英。
- 若纯环刀仍能靠无限挡弹站桩磨死精英，优先测试挡弹限制。若敌人因反复击退无法行动，再测试击退递减。刀数上限和每 5 级开放高阶池暂留作后续方案。

### 待确认

1. 纯环刀面对多数 Boss 时，是否保留靠走位、抓招式空档通关的路线？建议保留，代价是更慢、更危险。
2. 第一场精英战是否保留场上已有小怪作为护卫？建议暂停新刷怪，精英阵亡后恢复正常刷怪，暂停期间的刷怪量不补发。

### Noita 的启发：构筑要应对不同考题

用户以 Noita 的体验为例：清图、单体 DPS、范围伤害和输出是否容易兑现，是几项不同的能力。探索机动与生存也有自己的成长需求，后者还可以拆成生命上限、抗性和回复。某项发展得很好，仍可能因另一项短板而遇到威胁。

对《剑环》来说，可以先用下面几项检查构筑。它们是观察维度，暂不等于要新增对应的技能或数值系统。

| 能力 | 用什么场景检查 |
| --- | --- |
| 清潮与覆盖 | 多方向同时涌入小怪时，能否及时清出走位空间 |
| 单体输出 | 精英或 Boss 只露出短暂破绽时，能打掉多少血 |
| 输出可兑现性 | 目标后撤、隔着弹幕或混在小怪里时，能否打到想打的目标 |
| 机动与生存 | 能否安全换位，失误掉血后有没有恢复手段 |

环刀目前同时覆盖清潮、近身压制和挡弹。精英战可以检验输出可兑现性：环刀要追上目标，锁链可以缩短追击，天雷可以隔着距离打，但未必落在想打的目标身上。同一场遭遇能看出构筑之间具体差在哪里。

下一轮判断一张升级卡时，可以先问：它让玩家更擅长应对什么？选它之后，还有哪种威胁需要靠其他成长或操作来处理？
