# 剑环 Blade Orbit 游戏设计文档

版本：v1.0　日期：2026年11月2日  
对应游戏包：RatGameDesign / blade-orbit-ByCC

本文说明《剑环》的玩法、内容规模和关键规则，供策划、程序与美术制作近似游戏。目标成品是一款约三分钟战斗时间的俯视角像素生存游戏：玩家移动御剑角色，用自动旋转的剑刃杀敌、收集经验、选择随机强化，最终击败首领。升级选择和暂停不计入战斗时间，因此实际游玩会更长。

## 1 游戏定位与核心体验

**游戏类型**：单人、俯视角、自由移动、自动攻击、局内随机成长的短局生存游戏。原包以桌面浏览器键鼠操作为主。

**核心乐趣**：用走位把敌人引入剑刃轨迹，在包围中收集经验，逐步形成更密、更大、攻击方式更多的火力，再用这套构筑对抗弹幕首领。玩家主要判断移动路线、接敌距离和升级取舍。

复现时优先保留三种感受：

- **剑在扫，人在带剑**。剑刃围绕角色公转，玩家移动会改变攻击轨迹；靠近敌群收益高，也更容易让敌人穿过空隙贴身。
- **成长立即可见**。增加剑数、扩大剑环、增加逆向外环，再叠加飞剑、雷击和爆炸，形成明显的战力变化。
- **后半局改变压力来源**。前期应对围追，后期出现远程敌人，首领战加入需要走位穿越的弹幕；剑刃和震荡波同时具有消弹作用。

内容规模以一个角色、一种开放场地、四类普通敌人、一个两阶段首领为基准。完整近似版包含15种普通强化、4种组合进化、三选一升级、结算和本地记录；剧情、商店、装备背包和永久属性养成不属于本包的基础循环。

## 2 一局流程与操作

**流程**：标题页 → 初始双剑战斗 → 杀敌掉经验 → 靠近拾取 → 升级三选一 → 继续战斗与构筑 → 150秒首领登场 → 击败首领或生命归零 → 结算 → 重新开始。

每局从等级1、满血100、两把环绕剑开始。所有局内强化在重开时重置。击败首领才算胜利，倒计时归零只是触发首领战。

| 场景 | 操作 | 行为 |
| --- | --- | --- |
| 标题页 | 点击或任意开始键 | 开始新一局；M单独用于切换静音 |
| 战斗 | WASD或方向键 | 八方向移动，斜向速度归一化 |
| 战斗 | 按住鼠标 | 朝指针方向移动；存在键盘方向输入时优先用键盘 |
| 升级 | 1、2、3或点击卡片 | 选择对应强化 |
| 升级 | R或点击重抽 | 重新生成整组三张卡；每局共2次 |
| 战斗与暂停 | P或Esc | 暂停或继续；暂停时也可点击继续 |
| 全局 | M | 切换静音并记住设置 |
| 结算 | R、空格、回车或点击 | 重新开始，短暂延迟后可操作 |

窗口失焦时，战斗自动暂停并清空移动输入。战斗中的基础操作只有移动，攻击与已获得技能自动执行。升级界面暂停战斗，卡片出现约0.35秒后才接受选择，防止误触。

## 3 场地与基础战斗

### 3.1 场地和移动

场地为持续铺开的深色草地，没有影响行走的障碍、房间切换或地图终点。摄像机平滑跟随角色，敌人从视野外围持续接近，形成可向任意方向撤退的战场。

角色移动带有很短的加减速过渡，起步灵敏，停止时稍有缓动。普通敌人之间互相推开，避免完全叠成一个点；离玩家过远的普通敌人会被回收到视野外围，保持战斗压力。

以下距离和速度均以游戏的**逻辑像素**计，不是显示器像素。画面采用低分辨率绘制后放大，不能直接把这些数值作为其他引擎的世界单位。

| 参数 | 初始值 | 复现用途 |
| --- | --- | --- |
| 生命与最大生命 | 100 / 100 | 初始生存容错 |
| 移速 | 64逻辑像素/秒 | 约为史莱姆速度的2.9倍、蝙蝠的1.4倍 |
| 环绕剑数 | 2把 | 在圆周上均匀分布 |
| 剑环半径 | 24逻辑像素 | 决定接敌距离 |
| 旋转角速度 | 3.4弧度/秒 | 约1.85秒转一圈 |
| 基础伤害 | 7 | 多种技能共用的伤害基数 |
| 初始暴击率 | 5% | 可暴击攻击命中时判断 |
| 暴击倍率 | 2.5倍 | 环绕剑、投射飞剑可暴击 |
| 受伤后无敌 | 0.7秒 | 防止接触和弹幕瞬间重复扣血 |
| 经验吸附半径 | 30逻辑像素 | 靠近掉落物后自动吸向角色 |

### 3.2 剑环命中与防御

内环剑始终顺时针旋转，剑尖沿径向朝外。伤害判定跟随每一把剑的剑身，不把整个圆盘或整圈轨道视为持续伤害区域。敌人可以从两把剑之间穿过，甚至进入角色与剑环之间的空间。

同一把剑对同一个敌人的连续命中间隔为0.28秒；不同剑分别计算。命中产生白闪、伤害数字、粒子和径向与切向混合的击退，表现出“扫开敌人”的感觉。伤害有约±15%的随机浮动并取整。

剑刃接触敌方子弹会直接击碎子弹，不反弹。消弹依赖剑的实际位置，剑数和转速提高后防御覆盖随之增强。敌人与角色本体接触会扣血，子弹命中也会扣血；受伤时角色闪烁、屏幕边缘泛红并短暂停顿。

**制作要点**：先调好双剑时的空隙、接敌距离和击退，再做成长。若双剑已经构成没有空隙的全周保护，后续增加剑数和外环的价值会减弱。

## 4 经验与升级选择

普通敌人死亡掉落一颗经验宝石。史莱姆、蝙蝠通常给1经验，少量给3；骷髅、法师通常给3，少量给10。宝石留在地面，玩家靠近后自动吸附并拾取；击杀本身不直接增加经验。

等级1升等级2需要6经验，之后按当前等级L计算下一次需求：`向下取整(6 + 3.2L + 0.18L²)`。例如升到等级2后，下一次需求为13经验。升级时先出现短暂扩散光环并推开附近敌人，约0.35秒后进入暂停选择。

每次生成三张卡，玩家只能选一张。普通候选同组不重复，满级项目移出候选池。没有可用强化补足时，用“回复40生命”的烤鸡腿卡填充。若一次获得多级经验，依次提供相应次数的选择。

| 卡片品质 | 一次获得 | 表现与规则 |
| --- | --- | --- |
| 普通 | 该强化1级 | 蓝青色边框 |
| 稀有 | 该强化2级 | 金黄色强调，连续执行两级效果 |
| 史诗 | 该强化3级 | 紫色强调，连续执行三级效果 |
| 进化 | 一种进化效果 | 橙金色专属卡，显示两个前置强化图标 |

稀有和史诗卡直接增加同一项目的等级，因此“剑数+1”等效果会执行多次。普通强化剩余等级不足时不会生成超过其上限的品质。早期史诗概率约5%，到150秒时约11%；稀有概率约20%，其余为普通。

满足某种进化条件后，下一次生成卡组时，**第一张必定是一种已满足条件的进化**；若同时满足多种，则随机选一种。玩家仍须主动选中，才能获得该进化。每种进化每局只能获得一次，原有强化继续保留。

## 5 强化与构筑

下表的等级上限均指“本局通过卡片获得的强化等级”。例如初始已有2把剑，“再添一剑”最高6级后共有8把内环剑。

### 5.1 普通强化

| 强化 | 上限 | 实际效果 |
| --- | --- | --- |
| 再添一剑 | 6 | 每级增加1把内环剑，重新均匀分布 |
| 淬火锋刃 | 5 | 每级共用伤害基数乘1.3，多个技能随之提高 |
| 旋风 | 5 | 每级剑环转速乘1.25 |
| 巨剑 | 4 | 每级剑体积乘1.2、内环半径乘1.15；外环随内环半径变化 |
| 致命一击 | 5 | 每级暴击率增加10个百分点，暴击倍率保持2.5倍 |
| 疾风靴 | 4 | 每级移速乘1.12 |
| 磁石 | 4 | 每级经验吸附半径乘1.5 |
| 龙之心 | 5 | 每级最大生命加25，并回满生命 |
| 嗜血 | 3 | 已拥有时，普通敌人击杀有10%概率回复4生命；当前实现更高等级不增加该效果 |
| 飞剑诀 | 5 | 自动向近敌发射穿透飞剑；等级L时每轮L把，冷却为1.5×0.9^(L−1)秒，单次伤害为基数的1.3倍 |
| 天雷 | 5 | 每2.5秒随机选择最多L个可见敌人落雷，每处造成小范围伤害；伤害为基数的2.6×1.25^(L−1)倍 |
| 爆裂诅咒 | 4 | 普通敌人死亡时，每级增加15个百分点的爆炸概率；爆炸可击杀其他敌人并继续触发 |
| 震荡 | 3 | 每级剑环击退乘1.6；拥有后，伤害命中附带减速，敌人移速降至45%，持续0.5+0.3L秒 |
| 逆旋之环 | 4 | “再添一剑”达到2级后进入候选；1级生成3把外环剑，每升1级再加1把，最多6把 |
| 震荡波 | 5 | 周期性从角色位置释放范围冲击，伤害、强击退并消弹；基础冷却4秒，每后续等级乘0.88，伤害每后续等级乘1.25 |

外环以逆时针方向、内环80%的角速度旋转，半径为内环的1.75倍。它提供更远的拦截层和更密的覆盖，但两层之间仍存在空间。

补充几个影响玩法的技能规则：飞剑发射后沿直线飞行，不追踪转向；一轮优先分配给距离最近的不同敌人，对同一敌人每把飞剑只命中一次。落雷选择随机可见目标，不保证优先首领。普通爆炸半径26，伤害为基数的2.2倍，不伤玩家。震荡波1级半径76，每级再加6，伤害基数为3倍；对首领伤害减半。

### 5.2 组合进化

| 进化 | 前置条件 | 获得效果 |
| --- | --- | --- |
| 雷霆飞剑 | 飞剑诀3级＋天雷2级 | 飞剑可命中数量再加2；每次命中从命中点向附近最多3个其他敌人弹射闪电，闪电伤害为基数的1.1倍 |
| 圣焰剑环 | 再添一剑4级＋淬火锋刃3级 | 共用伤害基数乘1.4；环绕剑命中附加2秒灼烧，每0.4秒造成基数0.35倍伤害，再命中刷新持续时间 |
| 天崩地裂 | 震荡波3级＋震荡2级 | 主冲击范围增加30%，0.35秒后在角色当时位置释放余震；余震为主伤害60%、主范围85%；命中的普通敌人眩晕0.8秒 |
| 血爆 | 爆裂诅咒2级＋嗜血1级 | 死亡爆炸范围和伤害增加50%，每次爆炸回复1生命 |

圣焰进化后内环剑变为金色并带火焰；当前代码也为外环命中附加灼烧，但外环仍保持普通剑外观。进化应有明显音阶、扩散光环、短暂停顿和名称横幅，让玩家明确感到构筑发生变化。

**典型构筑方向**：剑数、转速和外环侧重持续拦截；飞剑与天雷侧重自动远程打击；震荡波与震荡侧重挤出安全空间；爆裂诅咒与嗜血侧重密集敌群中的连锁清场和回复。这些方向通过随机卡片组合实现，没有开局职业选择或互斥分支。

## 6 普通敌人与战斗节奏

### 6.1 四类敌人

| 敌人 | 基础生命 | 移速 | 接触伤害 | 行为与用途 |
| --- | --- | --- | --- | --- |
| 史莱姆 | 12 | 22 | 8 | 缓慢直追，早期主要目标，后期组成拥挤敌群 |
| 蝙蝠 | 6 | 46 | 5 | 快速接近并横向摆动，易被击退，考验剑环空隙和撤退路线 |
| 骷髅 | 42 | 27 | 12 | 耐打、较难击退，持续占据接敌空间 |
| 法师 | 24 | 20 | 8 | 靠近玩家但保持约70至95距离；太近会后退，每约2.6秒发射一枚瞄准弹，弹幕伤害7 |

普通敌人生成时的实际生命为：`基础生命 × (1 + 战斗秒数 × 1.6 / 45)`。生命按出生时刻确定，速度和接触伤害不随时间一起增长。敌人的变硬与玩家的强化相互追赶。

### 6.2 出怪安排

| 战斗时间 | 事件或新增压力 |
| --- | --- |
| 0秒起 | 史莱姆持续从视野外接近 |
| 约16秒后 | 蝙蝠进入随机刷怪池 |
| 32秒 | 第一波环形包围：28只蝙蝠 |
| 约44秒后 | 骷髅进入随机刷怪池 |
| 约63秒后 | 法师进入随机刷怪池 |
| 68秒 | 第二波环形包围：36只史莱姆 |
| 108秒 | 第三波环形包围：44只骷髅 |
| 150秒 | 清除当前普通敌人，首领“深渊领主”出场，普通刷怪停止 |

常规刷怪间隔从约0.9秒逐步缩短，最低0.11秒；每批数量从1只逐步增到5只。三次固定敌潮是在常规刷怪之外追加，围绕玩家约150距离均匀生成，并显示“敌潮来袭”与警报声。场上敌人数上限320。

制作近似版本时，优先还原“开局稀疏 → 敌群变密 → 远程弹幕加入 → 首领决战”的节奏。具体概率可以调，但不能只提高敌人生命而不改变敌群组成和空间压力。

### 6.3 稀有掉落与连斩

普通敌人死亡时，另有约0.6%概率额外掉落回复道具，拾取回复30生命；约0.3%概率掉落全场吸经验的磁石，只吸经验宝石，不吸其他道具。它与升级项目“磁石”是不同系统。

连续击杀增加连斩，超过2.2秒没有新击杀或角色受伤就清零。10连斩起显示计数，50连斩的倍数有额外提示。连斩与连续拾取经验会提高音效音高，用来放大连杀和收集反馈；连斩不提供额外伤害或奖励倍率。

## 7 首领深渊领主

首领在玩家上方约110距离登场，伴随警告、紫色扩散光环、咆哮、震屏和音乐切换。出场停顿约1.2秒后，缓慢追击玩家。接触伤害20，击退抗性很高。

首领实际初始生命以5000为基准，并根据登场时玩家的共用伤害基数D调整：`5000 × [1 + (D − 7) / 30]`。这是生成时的一次性计算。若只做近似游戏，可先固定生命后调试战斗时长；若还原原包，应使用这条规则。

### 7.1 三种攻击循环

首领按“环形弹幕 → 瞄准扇形 → 双向螺旋”循环。首轮攻击计时从出场后开始递减；普通阶段每次发动之间约2.4秒。剑刃和震荡波沿用消弹规则，玩家持续自动输出。

| 攻击 | 普通阶段 | 半血后 | 玩家应对 |
| --- | --- | --- | --- |
| 环形弹幕 | 同时向四周发射14枚，速度52，单枚伤害9 | 增为20枚 | 观察空隙穿行，或用剑刃拦截 |
| 瞄准扇形 | 朝玩家发射5枚扇形弹，速度78，单枚伤害9 | 增为7枚 | 横向移开瞄准方向，避免近距离吃满覆盖 |
| 双向螺旋 | 每0.07秒发一对相反方向子弹，连续18对，速度60，单枚伤害8 | 增为26对 | 随弹流移动，避免退入连续弹道 |

首领第一次召唤在约6秒后，之后普通阶段每8秒召唤5只小怪；蝙蝠和史莱姆随机出现于首领周围。首领战中仍可杀小怪捡经验并升级。

### 7.2 半血狂暴与结算

生命低于50%时狂暴，显示红色提示、扩散环和咆哮，首领血条改为红色。攻击间隔缩短为约1.7秒，弹幕数量增加，召唤改为每5秒8只小怪；攻击顺序保持不变。

首领死亡立即判胜，清理剩余敌人与敌方子弹，先播放约1.2秒的连续爆炸演出，再显示结算。角色生命归零则立即失败，播放碎裂粒子与失败音阶。

“整局约三分钟”是短局体验目标，原包没有三分钟强制结束规则。首领登场后的战斗长度取决于构筑和输出位置。

## 8 画面与声音要求

**画面方向**：低分辨率像素风，深绿草地、蓝色角色与钢色飞剑形成基础色组；紫色蝙蝠和首领、红色法师与敌弹用于区分威胁。场地用小块草地、花、石子重复铺设，角色、怪物按脚下位置排序。普通角色动画可用少量帧完成。

剑环必须有短弧形光迹和残影，使玩家能辨认旋转方向和攻击范围。敌人命中白闪并轻微挤压变形，死亡爆出像素粒子和经验。暴击数字更大、偏金色，并有很短的停顿；玩家受伤的停顿和震屏更强，低血量出现脉动红色边缘。

**战斗界面**：屏幕顶部是经验条；中央上方显示距首领降临倒计时，首领战时替换为名称与血条；左上显示击杀，右上显示等级与连斩，底部展示已获得强化及等级，角色脚下显示生命条。升级时暗化战场、横排三张卡，清楚显示名称、图标、品质、等级变化和作用，下方显示剩余重抽次数。

**标题与结算**：标题页提供开始操作说明、历史记录和4个进化图鉴格。结算显示胜负、战斗用时或存活时间、等级、击杀、最高连斩及本局构筑，标记新纪录并提示重开。

**声音方向**：使用短促的复古电子音。至少区分命中、暴击、击杀、经验拾取、升级、稀有卡、进化、消弹、玩家受伤、敌潮、首领出场与胜负。常规战斗配循环音乐，首领阶段提高速度和紧张感。原包用WebAudio实时合成，制作近似版本可换成音频素材，但需保留这些事件反馈；大量同类音效应限制同时触发频率。

## 9 存档与制作验收

### 9.1 本地记录

保存已结算局数、胜利局数、最快通关战斗时间、最多击杀、最高等级和已发现进化，静音设置单独保存。发现进化时即可记录，无须等到通关。存档用于展示成绩和收集进度，不增强下一局属性，也不限制进化再次获得。关闭页面后不保留当前局的战斗现场。

### 9.2 建议制作顺序

1. **先做基础战斗**。完成自由移动、跟随镜头、双剑公转、剑身命中、击退、接触伤害和一种追击敌人。先确认移动带剑和扫击的乐趣。
2. **接通成长循环**。完成掉落、吸附、经验升级、暂停三选一，接入剑数、伤害、转速、剑体积、生命与移速等基础强化。
3. **补齐整局**。加入四类普通敌人、定时敌潮、远程弹幕与消弹、150秒首领、半血变化和胜负结算。
4. **补齐构筑与表现**。接入全部技能、外环、4种进化、稀有品质、重抽、音效、本地纪录和进化图鉴。

### 9.3 近似版本验收标准

- 玩家只靠移动就能完成攻击，移速不受斜向输入加成；暂停和升级时，敌人、弹幕与战斗计时均停止。
- 初始两把剑有明确空隙，敌人能贴身；增加剑数和外环后，攻击覆盖与拦截能力明显变化。
- 杀敌、地面经验、吸附、三选一和继续战斗形成完整循环；稀有卡能一次增加多级，满级项目不会继续出现。
- 四类普通敌人能从速度、耐久和攻击方式上区分，三波包围及后期远程压力均可识别。
- 至少能实际做出并体验4种进化；满足前置后，下次卡组提供进化选择，并有足够清楚的反馈。
- 150秒后进入首领战，普通持续刷怪停止；首领有三种轮换弹幕、召唤和半血狂暴，死亡后正确进入胜利结算。
- 重开会清空局内等级与强化，本地历史成绩和进化图鉴仍保留。

以上参数用于建立接近原包的起点。手感调试优先观察剑环空隙是否可读、击退是否足够、捡经验是否需要取舍、首领弹幕能否看清，最后再调整通关时长和难度。
