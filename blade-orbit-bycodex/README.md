# 剑环 · Blade Orbit bycodex

版本 **v1.0.0**。独立编写的离线 HTML 游戏，玩法依据 RatGameDesign 的相关 Markdown 文档。

## 下次如何打开

在此文件所在文件夹双击 **start-game.cmd**，使用系统默认浏览器打开。也可以用 Chrome / Edge 直接打开 **index.html**。三个运行文件 index.html、style.css、game.js 需要保持在同一文件夹。

无需安装、联网、运行服务器或保留 Codex 会话。关闭电脑后仍可再次双击启动。声音需在点击开始后播放。历史成绩、静音设置、已发现进化保存在当前浏览器的本地存储中；浏览器、文件位置或打开方式改变时，记录可能不同。浏览器禁用存储时仍能游戏，但不能保存记录。

若浏览器不允许直接运行本地页面，可在已安装 Node.js 的电脑上运行 `node serve.cjs`，然后访问 http://127.0.0.1:8127 。启动窗口保持打开即可，关闭窗口会停止本地服务。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键，或在战场内按住鼠标 / 触屏 |
| 攻击、已获得技能 | 自动施放 |
| 选择升级 | 点击卡片，或 1 / 2 / 3 |
| 升级重抽 | R，每局 2 次 |
| 暂停、继续 | P / Esc，失焦自动暂停 |
| 声音 | M |
| 结算后重开 | R / 空格 / 回车 |

键盘移动优先于鼠标。初始双剑有空隙，身体碰敌会受伤；用剑身迎敌、及时捡灵力会更安全。

## 内容

- 四类常规敌人、32 / 68 / 108 秒敌潮、88 秒追猎法师。
- 180 秒后深渊领主登场；精英存活时等待，击败精英后至少保留 12 秒过渡。
- 首领有环射、扇射、螺旋、留有通道的弹墙、预警激光；半血狂暴和小怪召唤。
- 18 项基础强化，普通 / 稀有 / 史诗卡，4 种组合进化；锁链、串联、禁锢。
- 初始双剑、实际剑身碰撞、普通弹格挡、拾取吸附、连斩、合成音效和原创音序音乐。
- 首领紫弹与激光不能被剑刃或震荡波消除。激光锁定方向后，横向离开预警线。
- 中等和困难；右侧试剑场直接提供一套构筑体验首领，试剑场不保存战绩或进化发现。
- 本地历史记录、进化图鉴、胜负结算和重新开始。当前战斗现场不跨关闭保存。

本版以新 README 的精英、三分钟首领和不可格挡紫弹为准，其他细节按设计文档独立实现和调参，并非原包数值的逐项复刻。例如嗜血高等级提升回复、首领生命与普通敌人压力采用本版数值，未接入第三方音乐播放器。

## 验证与版本

安装 Node.js 后运行 `node --test tests/game.test.cjs` 可执行机制检查。已验证剑身间隙、方向归一化、暂停、经验拾取、升级池上限与前置、四种进化、重抽、精英首领时序、首领狂暴和激光、试剑场战绩隔离、锁链串联与禁锢。

浏览器检查覆盖标题、开局、移动、击杀拾取、暂停、首领试剑场与实际升级卡。自动检查不代表已用普通构筑实玩通关，也不保证所有随机构筑都已完成难度平衡；最终音乐听感仍需人耳评价。

项目内使用 Git 管理版本，入口文件名保持稳定。用 `git log --oneline` 查看变更，v1.0.0 标签对应本次交付。
